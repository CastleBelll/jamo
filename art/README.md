# JAMO Art & Audio

This directory contains the S8 asset passes: bright manuscript paper, charcoal ink,
restrained antique-gold accents, warm evening library light and porcelain letter figures.
The v2 contract and replacement sizes are in `ASSET_MAP.md`. Runtime game text remains
code/font data; generated character silhouettes and logo text are decorative assets.

## v2 production / integration handoff

- C: 17 textured brush buttons, hanji/ink panels, wooden HUD strip, rings, bars and tabs.
- F: 46 dry-brush ink/gold icons, status/variant marks and porcelain tiles.
- G: 3 Nanum OFL fonts; exact download URLs and complete licenses in `fonts/README.txt`.
- A: 20 ImageGen porcelain jamo figures, 256×256, shape-guide checked and bottom aligned.
- B: 4 ImageGen porcelain bosses, 512×512, distinct ink/empty/running/gold silhouettes.
- D: brush JAMO logo with checked Korean subtitle, walking-figure title background and
  dim-menu library variant; original `library/lib_bg.png` retained.
- E: top-down combat desk, normal/hit sentence strips and transparent ink vignette.

94 final PNGs and 3 fonts produced/replaced in v2. All model-generated outputs use
OpenAI's built-in ImageGen and are governed by OpenAI Terms, not an OFL/CC stock license.
Project-original C/F geometry and textures have no third-party asset restrictions;
font-derived shape guides use Noto Sans KR under OFL-1.1. Selected model originals and
source IDs remain under `_source_v2/`; prompt sets are documented in `ASSET_MAP.md`.
No API fallback or third-party paid-provider CLI was used. Malformed jamo and baked
checkerboard attempts were rejected; only true-alpha sprites were packaged. Native
sources remain straight alpha; finishing performs canvas crop/resize, not premultiplication.

Do not run the v1 generator over v2 outputs. `tools/build_ui_v2.py C/F` rebuilds only
the procedural groups; `tools/package_characters_v2.py` / `package_group_v2.py` normalize
selected ImageGen sources. Coordinator owns scene/theme wiring and Godot visual QA;
this asset branch does not alter code, scenes, click geometry, tests or project settings.

## ImageGen prompts

Mode: built-in ImageGen (`stylized-concept`). No external API key or paid provider CLI
was used.

Library/title background prompt:

> Create a polished 1920×1080 2D illustrated game background for a Korean word-defense
> game titled conceptually JAMO, but include absolutely NO letters, NO text, NO
> typography, NO logos, and NO UI buttons. Warm final-library interior at sunset, bright
> ivory hanji paper atmosphere, deep charcoal ink accents, restrained antique gold light,
> wooden writing desk in the lower third with an open blank book, bookshelves framing left
> and right, soft paper dust motes, subtle hand-painted ink-and-watercolor texture,
> inviting rather than dark, clean center negative space for title and menu UI,
> symmetrical readable composition, flat 2D illustration with modest depth, no people,
> no creatures, no 3D rendered characters. Production game background, crisp, no
> watermark.

Battlefield paper prompt:

> A clean, bright traditional Korean manuscript paper sheet filling the entire wide
> frame; warm ivory hanji fibers, extremely subtle horizontal writing guides, faint
> deckled texture at the far edges; flat hand-painted paper texture and restrained
> ink-and-watercolor game art; 16:9 full-frame surface with a quiet center for gameplay;
> softly luminous warm library light; absolutely no text, letters, symbols, logos,
> watermark, objects, or dark central vignette.

## Rebuild notes

Run `python art/tools/generate_assets.py` from the repository root. It requires Pillow
and SoundFile; generated OGG files use Vorbis. The two `*_source.png` files are the
selected ImageGen inputs and must remain beside their derived 1920×1080 outputs.

See `ASSET_MAP.md` for the complete ID-to-path contract used by scene integration.
