# 한글 자모 아이들러 --- 단어 계열 및 효과 설계 v0.1

## 1. 게임 핵심 구조

-   맵은 하나이며 몬스터들은 플레이어를 공격하지 않고 돌아다닌다.
-   플레이어는 마우스로 몬스터를 클릭해 처치한다.
-   몬스터를 클릭할 때마다 **에너지 1**을 소비한다.
-   에너지가 0이 되면 해당 Day가 종료된다.
-   몬스터 처치 시 **골드**를 획득한다.
-   Day 종료 후 제시되는 **자음/모음 후보 중 하나를 선택**한다.
-   선택한 자모를 통해 단어를 완성한다.
-   완성한 단어와 단어 효과는 **영구 해금**된다.
-   골드 및 골드로 구매한 업그레이드도 **영구 유지**된다.
-   상위 단어는 특정 선행 단어를 해금해야 제작 가능하다. 예: `불 → 화염`
-   자모 선택지와 리롤은 골드로 강화할 수 있지만 최대치는 낮게 제한한다.

## 2. 프로토타입 공통 기준값

  항목                         초기값
  ----------------------- -----------
  하루 최대 에너지                 20
  기본 클릭 피해                    1
  기본 몬스터 HP                    3
  일반 몬스터 기본 골드            1G
  클릭당 에너지 소비                1
  Day 종료                   에너지 0
  상태이상 동시 적용             가능
  상태이상 처치 골드        정상 지급

> 수치는 v0.1 프로토타입 기준이며 플레이 테스트 후 조정한다.

# 3. 화염 계열

**정체성: 빠른 지속 피해 + 전이**

기본 화상: 지속 3초 / 틱 1초 / 틱 피해 1 / 중첩 불가 / 재적용 시
지속시간 초기화.

``` text
불
├─ 화염
│  └─ 고열
│     └─ 폭염
├─ 불꽃
│  └─ 화재
│     └─ 산불
└─ [폭염 + 산불] → 화염폭발
```

### 불

-   선행 없음.
-   화상 시스템 해금.
-   클릭한 몬스터에게 3초 동안 1초마다 1 피해.
-   총 기본 화상 피해 3.

### 화염

-   선행: 불.
-   화상 틱 피해 `1 → 2`.
-   기본 총 화상 피해 `3 → 6`.

### 고열

-   선행: 화염.
-   화상 지속시간 `3초 → 5초`.
-   현재 기준 총 피해 10.

### 폭염

-   선행: 고열.
-   화상 틱 간격 `1초 → 0.75초`.
-   단일 대상 화상 DPS 강화.

### 불꽃

-   선행: 불.
-   화상 상태 몬스터 사망 시 반경 80px 내 가장 가까운 몬스터 1마리에게
    화상 전이.

### 화재

-   선행: 불꽃.
-   전이 범위 `80px → 120px`.
-   전이 대상 `1 → 2마리`.

### 산불

-   선행: 화재.
-   전이된 화상도 다시 전이 가능.
-   최대 연쇄 3회.

### 화염폭발

-   선행: 폭염 + 산불.
-   화상 상태 몬스터 사망 시 15% 확률로 반경 100px 화염폭발.
-   폭발 피해 = 현재 화상 틱 피해 ×3.
-   폭발에 맞은 몬스터에게 화상 적용.

# 4. 독 계열

**정체성: 느린 누적 피해 + 고체력 몬스터 특화**

기본 독: 지속 8초 / 틱 2초 / 스택당 피해 1 / 최대 3스택 / 클릭마다
+1스택.

``` text
독
├─ 중독
│  └─ 맹독
│     └─ 극독
├─ 독성
│  └─ 독기
└─ [맹독 + 독기] → 부식
```

### 독

-   클릭한 몬스터에게 독 1스택.
-   최대 3스택.

### 중독

-   최대 독 스택 `3 → 5`.

### 맹독

-   스택당 틱 피해 `1 → 2`.
-   5스택 기준 틱당 10 피해.

### 극독

-   최대 스택 도달 시 남은 독 피해의 30%를 즉시 피해로 적용.

### 독성

-   독 지속시간 `8초 → 12초`.

### 독기

-   독 상태 몬스터 주변 100px 내 적에게 2초마다 20% 확률로 독 1스택
    전파.
-   독기로는 최대 2스택까지만 누적.

### 부식

-   선행: 맹독 + 독기.
-   독 1스택당 대상이 받는 클릭 피해 +4%.
-   5스택 기준 +20%.

# 5. 전기 계열

**정체성: 즉발 피해 + 연쇄**

``` text
전기
├─ 감전
├─ 번개
│  └─ 연쇄
├─ 벼락
└─ [연쇄 + 벼락] → 낙뢰
```

### 전기

-   클릭 시 20% 확률로 전기 발동.
-   추가 피해 = 기본 클릭 피해 ×1.

### 감전

-   전기에 맞은 몬스터 이동속도 2초 동안 -40%.

### 번개

-   전기 발동 시 가장 가까운 적 1마리에게 연쇄.
-   연쇄 피해 = 최초 전기 피해의 70%.

### 연쇄

-   최대 연쇄 3회.
-   피해 감쇠: 100% → 70% → 49% → 34%.

### 벼락

-   전기 발동 확률 `20% → 30%`.

### 낙뢰

-   선행: 연쇄 + 벼락.
-   매 10번째 클릭마다 반드시 발동.
-   화면 내 무작위 몬스터 3마리에게 각각 클릭 피해 ×2.

# 6. 출혈 계열

**정체성: 몬스터가 움직일수록 피해**

``` text
피
└─ 출혈
   ├─ 상처
   │  └─ 과다출혈
   └─ 혈흔
      └─ 혈폭
```

### 피

-   출혈 시스템 해금.
-   클릭 시 5초간 출혈.
-   출혈 상태에서 50px 이동할 때마다 1 피해.

### 출혈

-   이동 피해 `1 → 2`.

### 상처

-   출혈 지속시간 `5초 → 8초`.

### 과다출혈

-   출혈 중 다시 클릭하면 남은 출혈 지속시간 +2초.
-   최대 10초.

### 혈흔

-   출혈 상태 몬스터가 이동한 자리에 3초간 혈흔 생성.
-   다른 몬스터가 지나가면 1 피해.

### 혈폭

-   출혈 상태 몬스터 처치 시 반경 80px 내 적에게 현재 출혈 지속시간의
    50%를 가진 출혈 적용.

# 7. 얼음 계열

**정체성: 감속 + 정지 + 클릭 편의성**

``` text
얼음
└─ 냉기
   ├─ 빙결
   │  └─ 서리
   │     └─ 동상
   └─ 한파
```

### 얼음

-   클릭 시 20% 확률로 2초간 이동속도 -30%.

### 냉기

-   감속 `30% → 50%`.

### 빙결

-   감속 상태 몬스터 클릭 시 20% 확률로 1.5초 정지.

### 서리

-   빙결 종료 후 3초간 이동속도 -30%.

### 동상

-   빙결 상태 몬스터에게 클릭 피해 +50%.

### 한파

-   화면 내 모든 몬스터 기본 이동속도 -10%.

# 8. 힘/충격 계열

**정체성: 직접 클릭 피해 + 강한 한 방 + 범위 충격**

``` text
힘
└─ 강타
   ├─ 괴력
   └─ 충격
      └─ 충격파
         └─ 파괴
```

### 힘

-   기본 클릭 피해 `1 → 2`.

### 강타

-   클릭 시 10% 확률로 피해 ×2.

### 괴력

-   강타 확률 `10% → 15%`.
-   강타 피해 `×2 → ×2.5`.

### 충격

-   강타 발생 시 반경 60px 내 몬스터에게 본 피해의 30%.

### 충격파

-   범위 `60px → 100px`.
-   광역 피해 `30% → 50%`.

### 파괴

-   HP 20% 이하 일반 몬스터 클릭 시 즉시 처치.
-   보스/특수 몬스터 제외.

# 9. 골드 계열

**정체성: 영구 경제 성장**

### 돈

-   모든 골드 획득량 +10%.

### 금

-   선행: 돈.
-   황금 몬스터 해금.
-   출현 확률 2%.
-   보상 일반 몬스터 ×5.

### 황금

-   선행: 금.
-   황금 몬스터 보상 `×5 → ×8`.

### 재물

-   선행: 돈.
-   모든 골드 획득량 추가 +15%.

### 부자

-   선행: 재물.
-   Day 종료 시 그날 획득 골드의 10% 추가 지급.

### 대박

-   선행: 황금 + 부자.
-   황금 몬스터 처치 시 5% 확률로 해당 보상 ×10.

# 10. 에너지 계열

**정체성: 하루 행동량 증가**

### 밥

-   최대 에너지 `20 → 22`.

### 체력

-   선행: 밥.
-   최대 에너지 +3.

### 휴식

-   선행: 체력.
-   Day 시작 시 10% 확률로 에너지 +3.

### 절약

-   선행: 체력.
-   클릭 시 5% 확률로 에너지 미소모.

### 집중

-   선행: 절약.
-   에너지 미소모 발동 후 다음 클릭의 골드 +50%.

### 활력

-   선행: 휴식 + 집중.
-   최대 에너지 +5.

> 골드 영구 업그레이드를 포함한 최종 에너지는 약 40\~50 선에서 제한
> 검토.

# 11. 행운 계열

**정체성: 특수 몬스터 및 자모 선택 보정**

### 운

-   특수 몬스터 출현 확률 +5%.

### 행운

-   선행: 운.
-   황금/특수 몬스터 등장 확률 추가 +10%.

### 기회

-   선행: 행운.
-   Day마다 최소 한 번 특수 몬스터 등장.

### 복

-   선행: 운.
-   Day 종료 자모 선택 시 10% 확률로 후보 +1.
-   시스템 최대 선택지 제한은 넘지 않음.

### 대운

-   선행: 복.
-   Day당 첫 자모 리롤은 리롤 횟수를 소비하지 않음.

### 기적

-   선행: 기회 + 대운.
-   Day당 1회, 에너지가 0이 될 때 10% 확률로 에너지 3 회복.

# 12. 클릭/자동화 계열

**정체성: 클릭 편의 → 후반 자동화**

### 손

-   클릭 판정 반경 +10px.

### 손길

-   선행: 손.
-   클릭 판정 반경 추가 +10px.

### 자동

-   선행: 손길.
-   10초마다 일반 몬스터 1마리 자동 클릭.
-   자동 클릭도 에너지 1 소비.

### 속도

-   선행: 자동.
-   자동 클릭 주기 `10초 → 8초`.

### 기계

-   선행: 속도.
-   자동 클릭 주기 `8초 → 5초`.

### 공장

-   선행: 기계.
-   자동 클릭 시 현재 화면에서 골드 가치가 가장 높은 일반 몬스터 우선
    선택.

# 14. 영구 성장 원칙

다음은 모두 영구 유지한다.

-   보유 골드
-   골드로 구매한 업그레이드
-   최대 에너지
-   자모 선택지 증가
-   자모 리롤 횟수
-   기타 시스템 업그레이드
-   완성한 단어
-   단어 능력
-   단어 계열 진행도
-   Day 진행도

단어는 한 번 완성하면 다시 제작할 필요가 없다.

# 15. 상위 단어 해금 원칙

상위 단어는 선행 단어가 없으면 제작 후보에 등장하지 않는다.

``` text
불 미해금
→ 화염 잠금
→ 불꽃 잠금

불 해금
→ 화염 제작 가능
→ 불꽃 제작 가능

화염 해금
→ 고열 제작 가능

불꽃 해금
→ 화재 제작 가능
```

자모는 몬스터에게서 누적 재화로 획득하지 않는다. **Day 종료 시 제시되는
자모 중 하나를 선택**한다.

# 16. 골드 업그레이드 방향

-   최대 에너지 증가
-   기본 클릭 피해 증가
-   기본 골드 획득량 증가
-   자모 선택지 `2 → 3 → 최대 4`
-   자모 리롤 `0 → 1 → 2 → 최대 3`
-   자모 후보 잠금
-   특수 몬스터 출현 확률
-   몬스터 최대 동시 등장 수
-   황금 몬스터 출현 보정
-   자동화 편의 기능

자모 선택지와 리롤은 과도하게 늘리지 않는다.

# 17. 후반 밸런스 주의사항

모든 단어 능력이 영구이므로 장기적으로 화상, 독, 출혈, 전기, 빙결, 강타
등이 동시에 해금된다.

모든 효과가 클릭 한 번에 항상 발동하면 후반 밸런스와 시인성이 무너질 수
있으므로 프로토타입 이후 다음 중 하나를 검토한다.

1.  **활성 속성 슬롯:** 전투 속성 2\~3개만 활성화. 경제/에너지/행운은
    항상 적용.
2.  **발동 확률 분산:** 여러 속성 보유 시 각 발동률 조정.
3.  **속성 장착:** 해금은 영구지만 플레이 전에 사용할 속성을 선택.

# 18. 개발 데이터 구조 제안

Godot에서는 단어를 하드코딩하지 않고 Resource/JSON/CSV 등 데이터
기반으로 관리한다.

``` text
id
word
category
prerequisites
effect_type
base_value
value_type
duration
tick_interval
proc_chance
radius
max_stack
chain_count
description
```

예시:

``` text
id: fire_001
word: 불
category: fire
prerequisites: []
effect_type: unlock_burn
base_value: 1
duration: 3.0
tick_interval: 1.0
proc_chance: 1.0
radius: 0
max_stack: 1
```

``` text
id: fire_002
word: 화염
category: fire
prerequisites: [fire_001]
effect_type: burn_damage
base_value: 2
```
