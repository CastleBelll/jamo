# JAMO — 디테일 밸런스 v0.3

2026-09-11 / 기준 원본 v0.2. [게임 규칙 v0.7](JAMO_02_game_design_v0.7.md), [세계관 v0.3](JAMO_01_story_world_v0.3.md)과 함께 사용한다.

모든 값은 **구현 시작값**이다. 계산 검증과 사람의 플레이 검증을 구분한다. ‘목표’ 수치는 측정 결과가 아니다. 이 문서의 표가 유일한 수치 기준이며 기존 HP 지수식·가격표·효과 예시를 함께 적용하지 않는다.

## B1. 전투 단위·공통 수식

| 항목 | 시작값 | 목적 / 조정 기준 |
|---|---:|---|
| 수동 기본 피해 | 1.0 | W1 일반 적 2회; 무빌드 후반 난도는 의도적 |
| 수동 입력 간격 | 0.25초 | 최대 4회/초, 누르고 있기 허용; 실제 타깃 변경 부담을 측정 |
| 안정도 | 100 | 실수 여유; 연구 포함 최대 110 |
| 일반 적 도달 피해 | 8 | 13회 무방어 누락이면 패배; W1 단독 즉사 없음 |
| 기본 치명 확률 / 배율 | 0% / 1.5배 | 칼로 활성; 치명 확률 상한 35% |
| 피해 감소 합산 상한 | 35% | 방어로 패턴 무시하지 못하게 함 |
| 자동 타격 공통 피해 기준 | 기본 피해 1.0 | 수동 공격 보너스·치명과 분리 |
| Wave 완료 회복 | 4 | 무피해 상태에 낭비 허용; 적을 일부러 놓칠 이익 없음 |

수동 피해 = 1.0 × (1 + 수동 피해 증가 합) × 치명배율(해당 시). 검의 조건부 추가량도 같은 증가 합에 더한다. 증가 합 상한 +100%. 소수 HP/피해를 유지하고 UI만 소수 첫째 자리까지 표시한다. 피해 사건별 정수 내림을 하지 않는다.

안정도 피해 = 원피해 × (1 − min(0.35, 감소 합)) × (1 + 위험의 받는 피해 증가). 보호막이 먼저 흡수한 뒤 안정도를 깎는다. 안정도와 보호막은 0 이상, 회복은 최대 안정도를 넘지 않는다. 피해 감소·위험 배율은 서로 한 번씩만 적용한다.

화상: 1초마다 피해, 첫 틱은 1초 후. 재적용은 만료시각만 갱신하고 틱 시계를 미루지 않는다. 중독: 각 스택이 독립 수명을 가지며 최초 중독 부여부터 1초 간격 공통 틱에서 살아 있는 스택 수만큼 피해. 스택 추가·갱신으로 틱 시계를 초기화하지 않는다. 마지막 수명 시각과 틱이 같으면 틱을 준 뒤 만료한다. 둔화는 가장 강한 비율만 적용하고 지속시간은 해당 효과 재적용 시 갱신한다. 이동속도 최저 50%, 보스 자체는 이동하지 않아 둔화 효과 없음. 부하에는 정상 적용한다. 보스 화상·중독 피해는 정상이며 무적 면역을 추가하지 않는다.

## B4. 회수·덱 정리

일반 자모 정화마다 25% 동일 자모 회수. 같은 Wave에서 4연속 미회수면 다음 정화는 확정이다. Wave당 회수 상한 6, 중복 자모 허용. 일반 Wave 선택 행동 1회, W5/10/15 뒤에는 선택 2회와 제거 1회. 후보가 모자라면 가능한 수만 선택한다. 보스 본체는 W5에 ㅁ 두 토큰, W15에 ㅇ 두 토큰을 보장하고 일반 회수 상한과 별도다. W10 본체는 자모를 주지 않으며 부하의 회수만 사용한다. W20 뒤에는 정리가 없다.

기본 확률에서 8/10/14/20/24회 정화 시 피티·상한 포함 기대 회수는 각각 2.415/3.086/4.316/5.633/5.939개다. 목표는 초반 후보 2~4개, 후반 4~6개다. 후반에는 상한에 자주 도달하며 추가보다 교체를 판단한다. 전부 정화한 조건과 일부 놓친 조건을 별도 측정한다. 미회수 상태를 보상 화면에서 숨기지 않는다. 드랍 없는 Wave가 실제 전체의 10%를 넘으면 정화율부터 확인한 뒤 드랍률을 5%p 단위로 조정한다. 덱 선택이 자동 추가로 굳으면 드랍을 늘리지 말고 교체 UI와 목표 힌트를 먼저 검토한다.

## B5. 단어 요구 빈도 → 스폰

B7 기본 22개만 빈도에 포함한다. 합성 결과는 재료 단어에서 만들어져 직접 자모를 뽑지 않으므로 제외한다. 각 단어의 중복 자모를 모두 세며, 같은 자모가 여러 번 필요하면 빈도에도 여러 번 반영한다. 기본 가중치는 `해금된 기본 단어의 요구 빈도 + 2`이며 해당 자모를 쓰는 해금 단어가 없으면 0이다. 일반 자모는 가중치를 합으로 나눈 확률로 추첨한다.

목표 핀의 자모가 현재 덱에 요구 개수보다 적으면 해당 글자 가중치에 ×1.15를 적용한 뒤 전체 재정규화한다. 여러 부족 개수가 있어도 1.15 한 번이다. 핀이 없으면 보정 없음. 이미 덱에 충분한 자모의 손패 미출현을 스폰으로 보정하지 않는다. 스폰 추첨과 Drop 추첨은 독립 RNG 스트림이다.

새 프로필은 위험 단어 세 개가 잠겨 있고 W5 최초 정화 뒤 다음 RUN부터 풀에 포함된다. 조건을 현재 RUN 중 충족해도 그 RUN의 콘텐츠 풀은 시작 시 스냅샷 그대로 유지한다. 따라서 신규 위험 단어를 즉시 만들라고 강요하지 않는다. 빈도표는 해금 전·후 두 상태를 분석 보고서에 남긴다. ㅡ·ㅌ 등 요구가 없는 자모는 실제 스폰/Starter에 넣지 않는다. 자모 종류 수는 빈도표의 양수 항목 수를 기준으로 한다.

## B7. Vertical Slice 단어 데이터

## B10. Gold·영구 성장·서고

일반 정화 Gold: W1~10 1G, W11~20 2G. B9 보스 본체는 표 값. Gold 증가는 기본 정화 Gold에 `(1+돈+욕심)`으로 합산하며 보스 본체에도 적용한다. 기타 Clear/발견 Gold 보너스는 없다. 소수는 RUN 안에서 누적하고 정산 때 정수부만 지급, 잔여 소수는 RUN 누적에 남겨 다음 정산에 합친다. 종료 시 남은 1G 미만은 버린다. 이미 정산된 누적 정수부를 다시 지급하지 않는다.

무보너스 최대 수입 계산: 일반 W1~9 총 102G, W11~19 총 168정화×2=336G, 보스 본체 250G, 보스 부하 최대 42G → W20까지 최대 730G. 부하 조기 제거·누락 시 낮아진다. W10까지는 일반 102 + 본체 100 + 부하 최대 10 = 212G. 첫 RUN의 수입은 도달·정화에 따라 달라져 첫 실패에 무조건 연구 구매를 보장하지 않는다.

이후 Gold는 저축 가능하며 Slice에서 추가 사용처를 억지로 만들지 않는다. 공격력·속도·리롤·손패·Lock 연구는 없다. 연구에 투자하지 않아도 실력과 빌드로 W20 클리어 가능해야 한다. A/B 선택은 RUN 시작 때만 가능하고 해금 구매가 현재 덱을 교체하지 않는다.

복원도: 기본 단어 RUN 첫 성공 복원 +1, 같은 RUN 반복 Rank 상승은 추가 없음. 누적 1/3/6회에서 I/II/III. I=발견 기록, II=은색 책갈피, III=금색 책갈피. 전투 수치·재료 정보·레시피를 잠그지 않는다. 기록자가 같은 단어를 다른 문서에서도 읽어낸 흔적이다. 합성/보스는 별도 최초 발견 기록만 가진다.

서고 레이어: 기본 단어 최초 1종=책 제목·작은 등불, 6종=책등 추가, 12종=글줄 추가, 침묵 최초 정화=다른 필체, 탐욕 최초 정화=열린 책. 임계값은 발견한 서로 다른 기본 단어 수 기준. 합성/보스는 기본 단어 카운트에 더하지 않는다. 별도 업적 시스템 대신 기록 탭에 ‘첫 합성/첫 완주/기본 12종 발견’ 배지 세 개만 남긴다. 배지는 재화·전투 보상 없음.

## B11. 화면·가독성·오디오 예산

논리 화면 1920×1080, 16:9 전장을 비율 유지해 배치한다. 지원 최소 창 1280×720. HUD y=0~120, 전투 x=220~1700/y=150~860, 마지막 문장 y=880~940, 빌드 y=960~1080. 보스 중심 (960,260), 최대 글자 영역 360×100. 스폰 중심 x=480/960/1440, y=370; 두 하위 경로는 각각 x±65, y=850의 같은 x 도달점까지 내려온다. 보스는 경로 위쪽 빈 구역에 배치한다. 문장 연결선이 각 도달점을 문장에 이어 준다.

일반 자모 시각 56×56px, 클릭 원 지름 76px, 같은 하위 경로 루트 간 최소 92px. 대응물은 90px, 보스 클릭 영역은 글자 영역을 덮는 캡슐. 일반 클릭 영역은 글리프 모양과 무관하다. 전투 중 최대 일반 적 8, 보스 부하 최대 4. UI 본문 최소 24px(720p 환산 16px), 주요 버튼 최소 64px 높이. 정보 확대는 정지 패널에서 100/125/150% 제공한다.

SFX 동시 재생 8, 동일 타격음 재생 간격 최소 0.05초, 보스 경고음은 우선순위 최상. 흔들림 0/50/100%, 기본 50%; 섬광 끄기 옵션. BGM 2루프(서고/전투)와 보스 강도 레이어 1개, SFX 공통 10종 이내로 시작한다. 파티클 총 활성 상한 256. 목표 60fps는 기준 PC 사양을 P0에서 기록한 뒤 실측하며, 이 문서 작성 시 성능 측정을 했다고 간주하지 않는다.

확률 보고서의 정책은 최적 정책이 아니다. 실패율뿐 아니라 후보 분포, 목표 선택률, 긴 단어 접근 Wave, 핀을 바꾼 이유를 본다. 무작위 정책과 목표 정책을 섞어 전체 승률 하나로 보고하지 않는다. 첫 RUN 실패를 일부러 유도하거나 빠른 클리어를 ‘콘텐츠 소모 문제’로 단정하지 않는다.
