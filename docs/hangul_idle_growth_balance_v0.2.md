# 한글 자모 아이들러 --- 영구 성장 및 골드 밸런스 설계 v0.2

> 목적: 실제 프로토타입 구현에 사용할 수 있도록 **Day 진행, 에너지,
> 몬스터, 골드 수입, 영구 골드 업그레이드, 자모 선택 성장, 단어 성장**을
> 하나의 경제 구조로 연결한다.\
> 아래 수치는 최초 밸런스 기준값이며 플레이테스트 후 조정한다.

------------------------------------------------------------------------

# 1. 성장 구조의 핵심 원칙

이 게임에는 리셋되는 런 성장 대신 **하나의 세이브에서 계속 누적되는 영구
성장**이 존재한다.

## 영구 유지 항목

-   현재 Day
-   보유 골드
-   골드 업그레이드
-   완성한 단어
-   단어 효과
-   단어 트리 진행도
-   자모 선택 관련 업그레이드
-   해금된 몬스터 종류
-   각종 시스템 해금

## 하루의 기본 루프

``` text
DAY 시작
  ↓
에너지 충전
  ↓
몬스터가 맵을 돌아다님
  ↓
플레이어가 원하는 몬스터 클릭
  ↓
에너지 소비 + 피해 + 골드 획득
  ↓
에너지 0
  ↓
DAY 종료
  ↓
오늘의 자모 선택
  ↓
단어 제작 진행 / 단어 완성
  ↓
영구 효과 적용
  ↓
골드 업그레이드 구매
  ↓
다음 DAY
```

핵심 분리:

-   **골드 성장 = 수치, 효율, 편의성 성장**
-   **단어 성장 = 새로운 메커니즘과 특수효과 해금**

  기본 자모 잠금            없음

기본적으로 에너지 20이면 하루에 최대 20번의 수동 클릭이 가능하다.

# 3. Day 진행과 몬스터 성장

Day가 올라갈수록 단순히 HP만 증가시키지 않는다.

## 권장 구간

  구간     Day        역할
  -------- ---------- --------------------------
  초반     1\~10      시스템 학습
  초중반   11\~25     첫 속성 트리 구축
  중반     26\~50     속성 조합 및 특수 몬스터
  중후반   51\~100    경제/자동화 성장
  후반     101\~200   상위 단어 및 고HP 몬스터
  장기     201+       무한 성장 구간

## 일반 몬스터 HP 공식

``` text
HP = 3 × 1.035^(Day - 1)
```

표시/실제 판정에서는 정수로 반올림한다.

예상값:

    Day   기본 HP
  ----- ---------
      1         3
     10         4
     25         7
     50        16
     75        38
    100        91
    150       506
    200     2,824

> Day 100 이후부터 단어 효과, 상태이상, 강타, 자동화 등이 충분히
> 누적되어 있다는 것을 전제로 한다.

# 4. 몬스터 골드 성장

몬스터 HP만 증가하고 골드가 그대로면 성장 체감이 나빠진다.

## 기본 골드 공식

``` text
BaseGold = 2 × 1.025^(Day - 1)
```

처치 시 최종 골드:

``` text
FinalGold =
BaseGold
× MonsterGoldMultiplier
× PermanentGoldMultiplier
× WordGoldMultiplier
```

예상 일반 몬스터 기본 보상:

    Day   기본 골드
  ----- -----------
      1           2
     10         2.5
     25         3.6
     50         6.7
     75        12.4
    100          23
    150          79
    200         273

소수점 골드는 내부적으로 누적하고 UI에서는 정수 표시를 권장한다.

# 6. 골드 업그레이드 전체 구조

골드 업그레이드는 5개 카테고리로 나눈다.

``` text
[활동]
에너지 / 에너지 효율

[클릭]
클릭 피해 / 클릭 범위 / 치명 클릭

[경제]
골드 획득 / 특수 몬스터 / 황금 보정

[자모 연구]
리롤 / 후보 수 / 잠금 / 집중 / 힌트

[환경]
몬스터 수 / 특수 개체 / 자동화 보조
```

# 10. 자모 연구 --- 핵심 영구 성장

자모 관련 업그레이드는 가장 강력하므로 가격을 공격/경제 업그레이드보다
높게 설정한다.

## 10.1 자모 선택지 증가

기본 후보:

**2개**

    단계   후보 수      가격 추가 조건
  ------ --------- --------- -----------
    기본         2        \- \-
       I         3    2,000G Day 10
      II         4   25,000G Day 40

**최대 4개.**

5개 이상은 지원하지 않는 것을 기본 원칙으로 한다.

    Lv   하루 리롤      가격 조건
  ---- ----------- --------- --------
     0           0        \- \-
     1           1    1,000G Day 5
     2           2    7,500G Day 25
     3           3   50,000G Day 60

리롤 횟수는 Day 시작 시 초기화된다.

영구 업그레이드 자체는 유지된다.

## 10.3 자모 잠금

해금 조건:

-   리롤 Lv.1
-   Day 15

가격:

**5,000G**

**1개**

## 10.4 목표 집중

현재 제작 가능한 단어 중 플레이어가 하나를 **목표 단어**로 지정할 수
있다.

목표 단어에 필요한 자모가 후보로 등장할 가중치를 증가시킨다.

    Lv   가중치 보너스      가격
  ---- --------------- ---------
     1             +5%    3,000G
     2            +10%    8,000G
     3            +15%   20,000G
     4            +20%   50,000G

최대 +20%.

**확정 출현은 절대 제공하지 않는다.**

    Lv   최대 동시 몬스터      가격

# 14. 단어와 골드 업그레이드의 역할 중복 규칙

같은 종류의 효과가 골드와 단어 양쪽에 존재할 수 있다.

단, 역할을 다르게 한다.

## 골드 업그레이드

**안정적인 수치 성장**

예:

``` text
골드 +5%
클릭 피해 +1
에너지 +1
리롤 +1
```

## 단어

**큰 효과 또는 새로운 규칙**

예:

``` text
불 → 화상 시스템 해금
번개 → 연쇄 공격
금 → 황금 몬스터 해금
절약 → 에너지 미소모 확률
산불 → 화상 연쇄 전이
```

따라서 `불`을 골드로 구매할 수는 없다.

# 15. 단어 제작 진행 속도

Day마다 기본적으로 자모 **1개**를 선택한다.

추가 자모를 영구적으로 2개, 3개씩 주는 업그레이드는 만들지 않는다.

단어 길이가 자연스럽게 제작 시간을 결정한다.

예:

``` text
불
ㅂ + ㅜ + ㄹ
최소 3 Day

화염
ㅎ + ㅘ + ㅇ + ㅕ + ㅁ
최소 5 Day
```

따라서 상위 단어는 강력하지만 완성까지 더 오래 걸린다.

자모 후보/리롤/집중 업그레이드는 **제작 속도를 직접 증가시키는 대신 실패
확률을 줄여주는 역할**을 한다.

# 16. 추천 플레이 진행 예시

## Day 1\~3

-   에너지 20
-   기본 클릭 피해 1
-   하루 25\~40G
-   에너지/클릭 피해 첫 업그레이드
-   첫 단어 제작 진행

## Day 4\~10

예상 누적 골드:

**300\~700G**

-   클릭 피해 2\~3
-   에너지 21\~23
-   골드 보너스 5\~10%
-   첫 핵심 단어 1\~2개 완성

## Day 10\~25

예상 누적 골드:

**2,000\~6,000G**

-   자모 후보 3개 해금
-   리롤 1회
-   속성 계열 본격 진입
-   특수 몬스터 등장

## Day 25\~50

예상 누적 골드:

**15,000\~50,000G**

-   리롤 2회
-   자모 잠금
-   목표 집중
-   여러 단어 계열 활성화
-   후보 4개를 향해 투자

## Day 50\~100

-   자동화 시작
-   상위 단어 제작
-   화염/독/전기 등의 트리가 눈에 띄게 성장
-   경제 계열 투자 가치 증가
-   고HP 몬스터 등장

## Day 100+

-   단순 클릭 피해보다 단어 간 시너지가 중요
-   자동화와 수동 클릭을 병행
-   상위 단어 트리 완성
-   희귀/특수 몬스터 파밍
-   장기 도감 완성 목표

# 17. 구매 가격 UI 규칙

가격은 다음 단계가 얼마나 먼지 직관적으로 보여야 한다.

추천 표기:

``` text
최대 에너지 Lv.4
24 → 25

500 G
```

구매 불가능:

``` text
보유 327 G / 필요 500 G
```

상위 시스템:

``` text
자모 선택지 III

3 → 4

25,000 G
조건: DAY 40
```

Day 조건과 골드 조건을 동시에 만족해야 구매 가능.

# 19. 구현 시 밸런스 상한

초기 프로토타입에서는 다음 상한을 넘기지 않는다.

  시스템               권장 최대
  ------------------ -----------
  골드 최대 에너지            30
  전체 최종 에너지        40\~50
  자모 후보                    4
  리롤                         3
  자모 잠금                    1
  목표 자모 가중치          +20%
  골드 기본 보너스          +50%
  에너지 미소모           총 20%
  동시 몬스터                 20
  클릭 범위 추가        총 +40px
  자동 클릭            6초당 1회

상한을 두는 이유는 후반에도 **단어 해금의 가치가 골드 업그레이드에
묻히지 않도록 하기 위해서다.**

# 21. v0.2 밸런스에서 반드시 테스트할 항목

프로토타입 후 다음 데이터를 기록한다.

-   Day별 평균 플레이 시간
-   하루 평균 클릭 수
-   하루 평균 골드
-   업그레이드 구매 간격
-   단어 하나 완성까지 평균 Day
-   리롤 사용률
-   목표 자모가 나오지 않아 답답함을 느끼는 구간
-   에너지가 너무 많아 Day가 길어지는 시점
-   상태이상으로 에너지 대비 처치 효율이 급격하게 증가하는 시점
-   골드가 남아돌기 시작하는 Day
-   자동화 해금 후 수동 클릭 필요성

특히 목표는 다음과 같다.

> **초반에는 거의 매일 작은 성장이 있고, 중반부터는 며칠 동안 모아서 큰
> 시스템을 해금하며, 단어를 완성하는 순간에는 골드 업그레이드보다 훨씬
> 큰 변화가 느껴져야 한다.**
