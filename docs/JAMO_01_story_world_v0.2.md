# 1. 세계관 한 줄 정의

> **뜻을 잃은 글자는 괴물이 되고, 뜻을 되찾은 글자는 다시 세계의 법칙이 된다.**

JAMO의 세계에서 언어는 단순한 의사소통 수단이 아니다.

말과 글은 세상을 설명하는 것이 아니라 **세상을 성립시키는 규칙**이다.

`불`이라는 말이 있기 때문에 불의 개념이 존재하고,  
`기억`이라는 말이 있기 때문에 기억이 존재하며,  
`길`, `빛`, `꿈`, `시간`, `사랑` 같은 말들이 세계의 의미를 붙잡고 있다.

그러나 어느 날 세상의 문장에서 글자가 떨어져 나가기 시작한다.

이 사건을 **백지화**라고 부른다.

---

# 2. 백지화

## 2.1 현상

백지화가 시작되면 완전한 단어가 자음과 모음으로 분해된다.

```text
불
↓
ㅂ ㅜ ㄹ
```

```text
기억
↓
ㄱ ㅣ ㅇ ㅓ ㄱ
```

```text
사랑
↓
ㅅ ㅏ ㄹ ㅏ ㅇ
```

단어가 분해되는 것과 동시에 해당 단어가 가진 의미도 세계에서 약해진다.

사람들은 단어를 잊기 시작하고, 기록은 비어가며, 책의 문장은 끊어지고,
결국 세계의 일부가 실제로 사라지기 시작한다.

---

# 3. 뜻을 잃은 자모

단어에서 떨어져 나온 자모는 완전히 소멸하지 않는다.

의미를 잃은 상태로 남아 끊임없이 움직인다.

이 자모들은 자신이 어떤 단어에 속해 있었는지 기억하지 못한다.

따라서 게임 속 `ㄱ`, `ㅁ`, `ㅇ`, `ㅏ` 등은 일반적인 생물형 몬스터가 아니라:

> **원래 어떤 말의 일부였으나 뜻을 잃고 폭주하는 글자의 잔해**

이다.

자모마다 움직임이 다른 이유 역시 글자의 형태가 곧 몸이기 때문이다.

- `ㅇ`은 굴러가듯 움직인다.
- `ㅁ`은 통통 튄다.
- `ㅅ`은 두 끝으로 빠르게 걸어간다.
- `ㅡ`는 바닥을 미끄러지듯 이동한다.

자모에 팔과 다리를 붙이지 않는다.

**글자 자체가 살아 움직이는 것처럼 보여야 한다.**

---

# 4. 플레이어 — 기록자

플레이어는 백지화 이후에도 글자를 읽고, 분해된 자모에 다시 의미를 부여할 수 있는 **기록자**다.

정확한 이름, 출신, 능력의 이유는 초반에 설명하지 않는다.

초반에 플레이어가 아는 것은 다음뿐이다.

- 자신은 아직 글자를 읽을 수 있다.
- 흩어진 자모를 정화할 수 있다.
- 정화한 자모를 조합하면 단어를 복원할 수 있다.
- 복원된 단어는 실제 힘을 가진다.
- 왜 자신만 가능한지는 모른다.

이 의문은 장기 스토리의 핵심 미스터리로 사용한다.

---

# 5. 마지막 서고

백지화 속에서도 완전히 사라지지 않은 마지막 기록 보관소.

게임의 Main Hub다.

명칭:

> **마지막 서고**

마지막 서고는 처음에는 거의 비어 있다.

- 책 대부분이 백지
- 꺼진 조명
- 텅 빈 책장
- 알아볼 수 없는 문장 조각
- 가운데 남아 있는 한 장의 기록

플레이어가 단어를 복원할수록 서고가 조금씩 되살아난다.

## 5.1 서고 변화

초기:

```text
복원된 단어 0~20
→ 대부분의 책장이 비어 있음
→ 배경음이 매우 단순
→ 희미한 조명
```

중기:

```text
복원된 단어 증가
→ 책장에 책 등장
→ 벽면 문장이 부분적으로 복원
→ 조명 증가
→ 새로운 기록 열람 가능
```

후기:

```text
많은 단어 복원
→ 서고 전체에 글이 돌아옴
→ 숨겨진 기록과 기억 등장
→ 마지막 문장의 정체에 가까워짐
```

서고의 변화는 단순 장식이 아니라 **영구 성장의 시각적 표현**이다.

# 6. 마지막 문장

백지화 이후에도 완전히 사라지지 않은 유일한 문장.

게임에서 플레이어가 지켜야 하는 대상이다.

기존 명칭인 `문장핵`은 사용하지 않는다.

정식 표기:

> **마지막 문장**

코드 내부에서도 가능하면 `LastSentence` 계열 명칭을 사용한다.

## 6.1 왜 중요한가

마지막 문장은 현재 세계에서 가장 강하게 남아 있는 완전한 의미다.

이 문장이 사라지면 남아 있는 언어의 연결도 붕괴한다.

뜻을 잃은 자모들은 남아 있는 의미에 본능적으로 끌리기 때문에 마지막 문장으로 몰려든다.

```text
뜻을 잃은 자모
↓
마지막 문장의 의미 감지
↓
오염된 문서 내부에서 접근
↓
문장에 닿음
↓
남은 의미를 침식
```

이 현상이 게임의 Wave다.

## 6.2 UI 표현

`HP`라는 내부 개념은 사용하되 플레이어에게는:

```text
마지막 문장 안정도
```

또는 간단하게:

```text
마지막 문장
████████░░
```

로 표시한다.

# 7. 오염된 문서

기록자는 마지막 서고에 보관된 **오염된 문서** 안으로 들어가 백지화를 되돌린다.

각 RUN은 하나의 문서를 복원하려는 시도다.

RUN 시작:

```text
마지막 서고
↓
오염된 문서 선택
↓
페이지 내부 진입
↓
Wave 1
```

RUN 실패:

```text
마지막 문장 붕괴
↓
해당 문서의 복원 실패
↓
문서가 다시 백지 상태로 되돌아감
↓
기록자는 마지막 서고로 귀환
```

하지만 기록자가 이미 서고에 기록한 것은 사라지지 않는다.

- Gold
- 복원 사전
- 단어 복원도
- 보스 기록
- 최고 Wave 기록
- 영구 연구

이것이 로그라이트 초기화와 영구 성장을 세계관 안에서 설명한다.

---

# 8. 자모를 공격하는 이유

플레이어는 자모를 죽이는 것이 아니다.

정확한 개념은 **정화**다.

자모를 클릭해 체력을 모두 깎으면:

```text
오염된 ㄱ
↓
균열
↓
먹/빛 조각으로 분해
↓
정화된 ㄱ 조각 회수 가능
```

플레이어-facing 문구는 가능한 범위에서 다음을 사용한다.

```text
Kill → 정화
Drop → 회수
Word Craft → 단어 복원
```

---

# 9. 단어 복원

정화된 자모를 다시 조합하면 단어에 의미가 돌아온다.

```text
ㅂ + ㅜ + ㄹ
↓
불
↓
'불'이라는 의미가 현재 문서에 복원
↓
화상 능력 활성
```

이 세계에서는:

> **단어의 의미가 곧 실제 법칙이다.**

따라서 단어의 게임 효과는 가급적 실제 뜻과 직관적으로 연결한다.

예:

```text
불 → 화상
독 → 중독
벽 → 방어
검 → 공격
운 → 확률
돈 → 경제
얼음 → 둔화/빙결
```

효과가 단어의 의미와 전혀 관계없어 보이는 설계는 피한다.

---

# 10. 복원 사전

기존 `단어 도감`의 세계관 명칭.

> **복원 사전**

처음에는 대부분의 항목이 비어 있다.

```text
복원된 단어
17 / ???
```

처음 만든 단어는 복원 사전에 등록된다.

단어를 여러 RUN에서 반복해서 복원하면 해당 단어의 **복원도**가 상승한다.

기존 `숙련도`라는 시스템 명칭 대신 플레이어-facing 명칭은 `복원도`를 우선한다.

---

# 11. 단어 보스

단어 보스는 백지화 속에서도 너무 강한 의미를 가졌기 때문에 완전히 분해되지 않은 단어다.

그러나 오랫동안 오염되면서 원래 의미가 극단적으로 뒤틀렸다.

정의:

> **의미가 뒤틀린 채 스스로 하나의 규칙이 되어버린 단어**

따라서 단어 보스의 패턴은 반드시 단어 뜻과 연결한다.

## 11.1 침묵

왜곡된 의미:

> 모든 말이 사라져야 완전한 침묵이다.

보스 능력:

- 플레이어가 복원한 단어 일부를 일시 봉인
- 일정 시간 단어 효과가 사라짐
- 효과음 일부를 줄이는 연출 가능

## 11.2 탐욕

왜곡된 의미:

> 존재하는 모든 것은 자신의 것이어야 한다.

보스 능력:

- 플레이어가 Gold를 얻을수록 보호막 획득
- 보상 욕심을 낼수록 전투가 어려워지는 구조

영구 Gold를 강제로 빼앗지는 않는다.

## 11.3 망각

왜곡된 의미:

> 기억이 존재하지 않으면 상처도 존재하지 않는다.

보스 능력:

- 현재 RUN 단어 일부를 일시 봉인
- 복원한 단어 이름/아이콘이 잠시 흐려지는 연출

도감이나 영구 복원도를 삭제하지 않는다.

## 11.4 분열

왜곡된 의미:

> 모든 것은 나뉘어야 완전해진다.

보스 능력:

```text
분열
↓
ㅂ / ㅜ / ㄴ / ㅇ / ㅕ / ㄹ
```

HP 구간마다 실제 자모로 나뉜다.

## 11.5 거울

왜곡된 의미:

> 보여진 것은 반드시 되돌려준다.

보스 능력:

- 같은 피해 유형을 반복할수록 해당 유형 저항 증가
- 한 종류의 단어만 극단적으로 쌓은 빌드에 압박

---

# 12. 보스 정화

단어 보스도 죽이는 것이 아니다.

정화 과정:

```text
오염된 '침묵'
↓
균열
↓
ㅊ ㅣ ㅁ ㅁ ㅜ ㄱ 으로 해체
↓
글자 재정렬
↓
원래 의미의 '침묵' 복원
↓
복원 사전 등록
```

화면 문구 예:

```text
'침묵'이 복원되었습니다.
```

일부 보스 단어는 이후 RUN에서 위험 단어/고급 단어로 사용할 수 있다.

---

# 13. 위험 단어

일부 단어는 복원되었더라도 본래 의미 자체가 강하거나 위험하다.

예:

- 욕심
- 광기
- 폭주
- 탐욕

이들은 오염된 단어는 아니지만, 사용자가 그 의미를 빌리는 대가가 존재한다.

정의:

> **금지된 단어가 아니라, 대가를 알고 사용하는 강한 의미**

---

# 14. Gold의 세계관

게임에서는 편의상 `Gold`, `G`라고 표시해도 된다.

세계관에서는 정화된 기록에서 떨어져 나온 **금빛 활자 조각** 정도로 설명한다.

용도:

- 마지막 서고 시설 강화
- 기록자의 정화 능력 연구
- 복원 도구 개선

UI는 단순하게 유지한다.

---

# 15. 지형의 세계관

전투장은 일반적인 숲이나 던전이 아니다.

플레이어는 오염된 문서의 **페이지 내부**에 들어간다.

기본 전투장은:

> **거대한 종이 위에 남아 있는 문장과 먹자국이 실제 지형처럼 변한 공간**

이다.

따라서 길은 도로가 아니라:

- 문장의 행
- 밑줄
- 문단 경계
- 종이 접힘
- 먹 번짐
- 찢어진 페이지

같은 요소로 표현한다.

---

# 16. 스토리 전달 방식

JAMO는 매 Wave마다 긴 대화를 보여주는 게임으로 만들지 않는다.

스토리는 다음 방식으로 전달한다.

1. 마지막 서고의 시각적 변화
2. 복원 사전의 기록
3. 단어 보스 첫 정화 시 짧은 기록
4. 특정 최고 Wave 도달 시 문장 조각
5. 숨겨진 책/메모
6. 마지막 문장의 복원

게임 흐름을 끊는 긴 컷신은 최소화한다.

---

# 17. 마지막 문장의 장기 미스터리

처음에는 마지막 문장을 모두 보여주지 않는다.

예:

```text
「_____ ________.」
```

게임 진행에 따라 일부가 복원된다.

예시 형태:

```text
초기
「_____ ________.」

중기
「나는 ___ ________.」

후기
「나는 너_ 기억____.」
```

정확한 최종 문구는 **현재 단계에서 확정하지 않는다.**

# 18. 장기 미스터리 질문

- 백지화는 왜 시작됐는가?
- 기록자는 왜 단어를 복원할 수 있는가?
- 마지막 문장은 누가 썼는가?
- 마지막 문장은 누구를 위한 문장인가?
- 단어 보스는 처음부터 악한 존재였는가?
- 왜 일부 단어는 다른 단어보다 강하게 남았는가?
- 세계가 완전히 복원되면 기록자는 어떻게 되는가?

이 질문들은 초반에 답하지 않는다.

# 19. 오프닝 연출 초안

목표 길이:

```text
20~30초
```

검은 화면.

```text
세상에는 수많은 말이 있었다.
```

화면에 단어들이 보인다.

```text
기억
사랑
이름
빛
```

하나씩 글자가 빠진다.

```text
기억
↓
ㄱ ㅣ ㅇ ㅓ ㄱ
```

자모들이 흩어지기 시작한다.

```text
어느 날,
글자들이 뜻을 잃었다.
```

카메라가 마지막 한 장의 문서로 이동한다.

뜻을 잃은 자모들이 페이지 위로 몰려든다.

```text
WAVE 1
```

게임 시작.

# 20. 분위기와 아트 제작 방향

## 20.1 전체 분위기

전체 분위기:

```text
귀여운 자모 움직임
+
신비로운 서고
+
조금 쓸쓸한 백지 세계
+
단어가 복원될 때의 따뜻함
```

아트 키워드:

- 오래된 종이
- 먹
- 활자
- 잉크
- 금빛 글자 조각
- 희미한 서고 조명
- 떠다니는 먼지
- 종이 섬유
- 지워진 문장
- 다시 나타나는 글자

과한 보라색 네온/AI풍 색감은 피한다.

## 20.2 2D 표현 원칙

JAMO의 기본 비주얼은 **2D 일러스트와 2D 스프라이트**로 확정한다.

핵심 콘텐츠 제작에 Blender나 3D 모델링을 요구하지 않는다.

목표는 현실적인 입체 렌더가 아니라:

- 따뜻한 종이 질감
- 손으로 그린 듯한 잉크 흔적
- 단순하고 읽기 쉬운 자모
- 작고 귀여운 움직임
- UI와 자연스럽게 연결되는 평면적인 화면

이다.

배경은 한 장의 페이지 일러스트를 중심으로 만들고,
먹 번짐·찢김·오염·교정부호 등은 별도의 2D Overlay로 추가한다.

자모는 `Sprite2D / AnimatedSprite2D`로 표현하며,
강한 원근이나 사실적인 3D 조명은 사용하지 않는다.

약간의 입체감이 필요할 경우에도 다음 정도만 사용한다.

- Drop Shadow
- 간단한 명암
- Scale / Squash
- 작은 회전
- 2D Particle
- Shader 왜곡

즉, **2D로 직접 제작하고 Godot 안에서 움직임과 이펙트로 완성도를 올리는 방식**을 기본 제작 파이프라인으로 한다.
